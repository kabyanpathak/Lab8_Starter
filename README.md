## Graceful Degradation and Service Workers
Graceful degredation means that app keeps working when the optimal conditions fail, like internet going out.

Service workers are the tool that makes this possible. When network fails the service worker catches the failed requests and serves saved files instead, keeping your app alive and functional rather than crashing.
